# La calle es de todos

Campaña ciudadana (PWA) para que en Caucasia (Antioquia) no se cierren las calles para fiestas y actividades familiares sin permiso.

## Qué hace
- Explica a quién afecta una calle cerrada: ambulancias, bomberos, vecinos, niños y adultos mayores.
- Test de 4 preguntas sobre la norma.
- Multas 2026 (Ley 1801 de 2016): art. 140 num. 4 (tipo 1, $233.454), art. 33 num. 1 lit. a (tipo 3, $933.816), art. 140 num. 6 (tipo 4, $1.867.632). Calculadas con el salario mínimo 2026 de $1.750.905.
- Cinco pasos para celebrar bien.
- Genera la solicitud de permiso para la Alcaldía y el aviso para el grupo de WhatsApp de la cuadra.
- Qué hacer si le cierran la calle, con acceso directo a la línea 123.
- No guarda datos personales. Fechas en hora de Colombia (America/Bogota).

## Publicar en GitHub Pages
1. Crear el repositorio `haroldco45/la-calle-es-de-todos`.
2. Subir todos los archivos de esta carpeta a la raíz.
3. Settings → Pages → Deploy from branch → `main` / root.
4. Queda en `https://haroldco45.github.io/la-calle-es-de-todos/`.

## Actualizar en enero
Cuando cambie el salario mínimo, recalcular las tres multas (4, 16 y 32 salarios diarios) y subir la versión del caché en `sw.js`.
